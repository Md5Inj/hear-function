# hear-function

Тренажёр слуха: слышать функцию, а не ноту. Ступени лада, аккордовые прогрессии и фрагменты реальных записей.

```
npm install
npm run dev      # http://localhost:3000
npm test
npm run build && npm start
```

База: `data/db.json` по умолчанию, либо MongoDB через переменную `MONGODB_URI` (обязательна на Vercel).
