# hear-function

Тренажёр слуха: слышать функцию, а не ноту. Ступени лада, аккордовые прогрессии и фрагменты реальных записей.

```
npm install
npm run dev      # http://localhost:3000
npm test
npm run build && npm start
```

База: `data/db.json` по умолчанию, либо MongoDB через переменную `MONGODB_URI` (обязательна на Vercel). Корпус песен тоже лежит в базе (коллекции `chordSongs` для аккордов и `melodySongs` для вокальных фраз): сервер сам импортирует его из `lib/songs-data.js` (результат конвейера `tools/`) и `lib/songs-db.js`, когда версия файла меняется; песни, правленные на служебной странице, импорт не перезаписывает.

Служебная страница базы (коллекции, поиск, просмотр, правка и добавление документов, удаление): настройки в `app.config.js`. `adminPath` задаёт адрес вида `admin_k3x9q2` (`admin`, подчёркивание и шесть символов), страница открывается по `/<adminPath>`, прямой `/admin` отвечает 404. Вход по своему логину и паролю администратора, не связанному с аккаунтами пользователей: администраторы хранятся в коллекции `admins`, первый создаётся из `adminLogin` и `adminPassword`, остальные добавляются на самой странице (поле `password` в открытом виде хэшируется при сохранении). `adminSecret` подписывает cookie входа. Переменные окружения `ADMIN_PATH`, `ADMIN_LOGIN`, `ADMIN_PASSWORD`, `ADMIN_SECRET` переопределяют значения файла.
